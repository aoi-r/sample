# v217 ドラゴン系ランダム孵化プール効果補強レポート

## ユーザー裁定の反映

- **ラプソーン**: 寄生先が死亡した時、付与者側の空きマスへ復活。優先順は `前列上段 → 前列中段 → 前列下段 → 後列上段 → 後列中段 → 後列下段`。
- **怪獣プスゴン**: 死亡時は同じ横列にある敵前列/後列の空きマスからランダム。既存処理を正として継続。
- **キースドラゴン / グレイグ系の正面判定**: 同じ行の敵前列・敵後列を「正面にいる全て」として扱う。既存処理を正として継続。
- **かみかぜ / 逆転への兆し**: ランダムなコスト2/3ユニットに職業制限はなし。構築可能な全職業ユニットから抽選する現行方針を維持。
- **ナイトキングれんけい**: 召喚者側リーダーのHP4回復で正しい。
- **パワフルバッジ解除**: 公式DB/効果欄に解除文面があるカードだけ対象。既存の `カーディナルナイト` / `あんこくまどう` 系は維持。

## v217で実装・補強したドラゴン系処理

### 召喚時

- アックスドラゴン: ユニット1体に1ダメージ。その後、受けるダメージ2倍を付与。
- ダッシュラン: 前列にいるユニット1体を後列へ移動。対象選択モーダルあり。
- ドラゴンキッズ: 正面にいる全ての敵ユニットへ1ダメージ。
- グレイトドラゴン: このユニットを除く自分の場/手札のドラゴン系数だけ+1/+1。
- ドラゴンガイア: 次の相手ターン終了時まで味方へ特技ダメージ耐性フラグを付与。
- やまたのおろち: 味方ユニット1体を選んで死亡させ、そのコスト分+攻/+HP。
- リザードフライ: 味方ユニット1体を1マス下へ移動。対象選択モーダルあり。
- ブラックドラゴン: ランダムな敵ユニット1体へ `1 + 他ドラゴン数×3` ダメージ。
- コドラ: このターン中、次に使うドラゴン系ユニットのコスト-2。
- グレイナル: 竜戦士の装具を手札に加える。ドラゴン系味方ユニットが敵ユニットを倒した時テンション+1する監視フラグを付与。
- いっかく竜: テンションスキル名を竜の導きに変更する暫定フラグ。
- ドラゴンロード: 他のドラゴン系味方ユニットを+1/+1し、手札ドラゴン系ユニットのコスト-1相当を登録。
- テラノザース: 自分のデッキに特技カードがないなら1ドロー。
- イエローファット: テンションを全消費し、消費数ぶん速攻1/1ファーラットを優先空きマスへ出す。
- ガメゴンレジェンド: ランダムな敵1体へ1ダメージを `3 + スキルブースト回数` 繰り返す。
- 怪竜やまたのおろち: 残りMPを全消費し、その数ぶん攻撃力+1。その後、自身の攻撃力ぶんランダムな敵ユニットへ1点ずつ割り振る。
- スノードラゴン: コスト4/5/6の特技カードから選んで手札に加えるモーダルを追加。

### 死亡時

- フェアリードラゴン: 味方リーダーのテンション+1。
- ドラゴンゾンビ: 正面にいる全ての敵ユニットへ3ダメージ。
- ラプソーン: 復活先優先順をユーザー裁定に修正。

### 攻撃時・攻撃後

- ベビーサラマンダ: 攻撃時GET(1)。既存BET4回変身処理も継続。
- グレイナル監視: ドラゴン系味方ユニットが攻撃して敵ユニットを倒した場合、テンション+1。
- ドランゴ: 味方リーダー攻撃後、ランダム横一列の敵ユニットと敵リーダーへ2ダメージ。
- りゅうせんし: 既存の「敵リーダー攻撃不可」「味方リーダーの攻撃扱い」を補強。

### ターン終了・回復誘発

- 樹氷の竜: 敵の場に氷塊があるなら敵リーダーに3ダメージ。
- フォレストドラゴ: 味方リーダーHP2回復。
- ドラゴンバゲージ: 味方リーダーのテンション+1。
- マーニャ：ドラゴラム: ランダム横一列の敵ユニットと敵リーダーに4ダメージ。
- ギガデーモン: ターン終了時GET(1)。
- リトルライバーン: 味方が回復する度、ランダムな敵1体へ2ダメージ。
- ベビーニュート: 味方ユニットのHPが回復する度、ランダムな敵1体へ1ダメージ、その後1ドロー。

## まだ要注意・追加確認したいもの

- **竜戦士の装具**: カード詳細が曖昧なため、v217では暫定トークンとして追加のみ。正式効果が分かれば差し替えたい。
- **竜の導き**: いっかく竜でテンションスキル名を変更する暫定フラグのみ。正式なテンションスキル効果が分かれば実装する。
- **ドラゴンガイアの特技ダメージ耐性**: 味方に耐性フラグを付けたが、全ての特技ダメージ経路がこのフラグを見るかは追加検証が必要。
- **スノードラゴンの選択候補**: コスト4/5/6の特技全体から抽出。公式の「3種類」が固定候補なら候補リストの裁定が必要。
- **ドラゴンロードの手札コスト-1**: 現状はターン中の次回ドラゴン系ユニット使用コスト軽減寄り。手札全体の永続/即時コピー置換が必要なら追加修正する。
