# v243 エッグラ&チキーラ 相手ターン開始時予想モーダル

## 反映内容

ユーザー裁定に合わせ、エッグラ&チキーラの召喚時処理を以下に整理した。

- エッグラ&チキーラは召喚時に召喚者が「タマゴ」または「ニワトリ」を選択する。
- 選択後、Firebase actionとして相手側に「予想が必要」という予約だけ送る。
- 相手側では、自分のターン開始時に同じ2択モーダルを表示して予想する。
- 相手の予想は召喚者側へ送信され、召喚者側で正誤判定する。
- 予想が外れた場合は、召喚者側で効果を解決し、解決結果を相手側へ返す。
- 予想が当たった場合は不発。

## 実装上の扱い

### 同期action

追加したaction種別:

- `eggChikiraPending`
- `eggChikiraGuess`
- `eggChikiraResolved`

### 効果解決

`v243ApplyEggChickenEffect(choice, sourceSide)` で、召喚者側を指定して解決する。

- `sourceSide='player'`: 自分のエッグラ&チキーラの効果。敵側に効果。
- `sourceSide='enemy'`: 相手のエッグラ&チキーラの効果。自分側に効果。

### タマゴ

召喚者から見た全ての敵ユニットと敵リーダーに3ダメージ。

### ニワトリ

召喚者から見た敵リーダーに3ダメージ。召喚者が2枚ドロー。

## 注意

これは召喚時効果なので、「場に出す」経路では予約されない。
ソロ/片画面検証用には従来のローカル予想モーダルも残している。
