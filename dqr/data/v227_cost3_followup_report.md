# v227 cost3 follow-up and event watcher audit

## 反映内容

- メーダクイン: 常在効果として、双方の本来コスト0の特技カードの使用コストを+1。
- ドッグスナイパー: ねらい撃ち。戦闘以外のダメージで敵ユニットが死亡するたび、自身の攻撃力+1。永続・重複。
- ウィッチレディ: 場にいる側が特技で敵ユニットを倒すたび、その側のリーダーのテンション+1。
- ブラウニー: 味方リーダーの攻撃で敵ユニットを倒すたび、自身の攻撃力+2。
- 旅立ちの王女: ムーンブルクの王女Lv3専用として、デッキ編成不可・通常ランダム生成対象外に変更。
- ジャミ&ゴンズ: 召喚時のみ選択モーダル。HP-2/1ドロー/敵リーダー2点、または攻撃力-2/におうだち/テンション+1。
- ロウ: テンションリンクを個別実装。テンション1で1ドロー、2でランダム敵1体へ2点、3で味方山札から3コストユニットを場に出す。

## 場に出す / 召喚の扱い

ロウのテンション3効果で出る3コストユニットは「場に出す」扱いです。召喚時効果は発動しません。基本キーワードはv223以降の putUnitIntoPlay 経路で保持します。

## ランダム生成除外

旅立ちの王女はヒーローLv3専用なので、randomUnitCardByCost / randomCostUnitCardV166 の通常ランダムプールから除外しました。

## コスト3残量目安

現在cards.json上の編成可能コスト3ユニット数: 208 件。
今回のv227は、ユーザー裁定が出た要注意7件を優先して反映しました。次は残りのコスト3未精査候補を続けて処理します。

## 要確認

今回の範囲で追加裁定が必要なものはありません。
ただし、ウィッチレディの「特技で倒す」判定は、現在の実装では特技ダメージsourceとして判定できるものを対象にしています。今後、独自source名で特技ダメージを出すカードを追加した場合は、そのsourceを特技扱いに含める必要があります。
