# v189 タバサLv3 / しんりゅう / イブール補強

## 変更点
- タバサLv1/Lv2は1ターン1回上限のまま維持。2回目以降は自動発動しない。
- 天空の英知を、使用済みコスト2以上特技プールから完全ランダムに1枚選び、元カード参照でコスト-1コピーを手札に加える処理へ変更。
- 天空の英知で手札に加えても、使用済みプールからは取り除かない。使用済みプールは同名/同カード複数回使用も記録する。
- しんりゅうの願い4種をDB本文ベースで確認し、召喚時選択効果としてコスト消費なしで実行。
- しんりゅう通常時は4択カード画像モーダル、超必中時は「すべてをねがう」ラベルを前面表示し、カード/ラベルどちらをタップしても全願い発動。
- イブールの相手特技コスト+1を場のイブール枚数スキャン方式に変更し、対人のリモート側イブールでも自分の特技コストへ干渉するよう補強。

## しんりゅう願い効果（DB本文確認）

|願い|効果|
|---|---|
|てふだをふやしたい|自分の手札が7枚になるようにカードを引く|
|ドラゴンをだしやすくしたい|自分の手札にあるドラゴン系のユニットカードのコスト-5|
|ドラゴンをつよくしたい|パワフルバッジ：ドラゴン系の味方ユニットを+2/+2|
|エッチなほんがよみたい|自分の手札にエッチな本を加える|

## 確定裁定
- ランダムユニットは範囲明記なしなら全ユニット対象。
- 召喚系/場に出す系は空いている限り出し、空きがなければ不発。
- 運命の輪由来の超必中はターン終了まで、ゾディアックコード由来は対戦中継続。
