# v192 イル＆ルカ ヒーロー枠組み

## 追加内容
- ヒーローカード `イル＆ルカ` を追加
- Lv1 `託されしたまご`、Lv2 `マスターへの道のり`、Lv3 `モンスターとの絆` / `めぐりあう仲間たち` を追加
- 送付スクリーンショットからカード画像を切り抜いて assets に配置
- 系統たまごカードを生成専用カードとして追加

## 挙動
- Lv1: 冒険者以外の系統を1つだけ持つ味方ユニットを選び、系統を記録。該当たまごを手札に加える。1回でLv2。
- Lv2: このターン中にたまごから生まれた、記録系統の味方ユニットにさくせん。2回でLv3。使用ごとにコスト-1。
- Lv3: `モンスターとの絆` から開始。使用ごとに `めぐりあう仲間たち` と交互に変化。
