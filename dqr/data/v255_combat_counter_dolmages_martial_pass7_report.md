# v255 combat counter / Dolmages / martial priority pass7

## 目的
v254で残っていた「反撃」「かばう系」「魔性の道化師ドルマゲス」を対戦エミュレータで固め、その後PENDING先頭の武闘家カード群を進めた。

## ユーザー確認の反映
- はやぶさ斬り: 1ダメージを2回で確定。
- 被攻撃時、対象が攻撃力を有していれば反撃する。
- リーダーも同様に反撃する。
- リーダー反撃では、防御側リーダーが武器を装備していても武器耐久値は減らない。

## 主な修正
- リーダー反撃を実装。ユニット→リーダー、リーダー→リーダーの両方を検査。
- 攻撃側武器だけ耐久を消費し、防御側リーダーの武器耐久は反撃では減らない。
- かばう: 有効中は相手の攻撃対象をリーダーに制限。cardPlayed action replayでも相手クライアントに反映。
- かばうの心得: かばう中のリーダー被ダメージを1軽減。
- やいばのボディ: リーダーが攻撃された時に攻撃側へ1ダメージ反撃。
- 魔性の道化師ドルマゲス: 召喚時、両プレイヤーの手札の特技カードのコスト-5。召喚者から見て次の相手ターン終了時に解除。action replayでも反映。
