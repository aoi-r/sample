# v280 ぷちメタルGET・死亡同期修正

## 修正内容

1. **ぷちメタルのGET+ドロー同時発生に見える挙動を修正**
   - 旧実装ではPvPの `endTurn()` 内で、ターン終了処理の直後に自分の次ターン開始処理まで前倒ししていました。
   - そのため、ぷちメタルの「自分のターン終了時GET(1)」と通常1ドローが同じタイミングで見えていました。
   - v280では、ターン終了時はGETのみ処理し、通常1ドロー/MP更新はFirebaseの `currentTurnPlayerId` が自分に戻った時だけ行います。

2. **ぷちメタルGETは1体につき1回だけ**
   - `_puchiMetalEndGetDone` を維持し、同じぷちメタルが次の自分ターン終了を迎えても再GETしないことを確認。

3. **PvPリモート側のHP0残りを修正**
   - リモートで `damageApplied` / `counterDamage` / `attackResolved` / `unitDeath` を受信した後、`resolveDeaths()` を安全に呼びます。
   - これで攻撃した側では消えているのに、攻撃された側ではHP0表記で残るケースを掃除します。
   - プチファイター（シンクロ2相当HP2）に2ダメージを受けた場合、受信側でも盤面から除去されることを検証。

4. **選択待ちの12秒自動解除を無効化**
   - v270の「選択待ちが長すぎるため自動解除」を削除。
   - 対象選択・マス選択は長考しても勝手にキャンセルされません。

## 重点テスト

- ぷちメタルがターン終了時にGET(1)だけを行い、通常ドローはまだ発生しない。
- Firebaseで自分のターンに戻ったタイミングで1ドローする。
- 同じぷちメタルは2回目のターン終了でGETしない。
- リモート側のプチファイターHP0残りを死亡処理で除去する。
- v270の12秒自動選択解除文字列が実行コードから消えている。
