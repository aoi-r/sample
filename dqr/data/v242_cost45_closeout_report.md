# v242 コスト4/5ユニット closeout pass3 + ランタイム堅牢化

## 目的
v241で残った `remaining_for_next_pass` / `v241_remaining_for_next_pass` / `v241_partial_guarded` / `runtime確認待ち` を、公式DB由来の cards.json 効果文から読める範囲でさらに実装・補強した。

## 実装・補強した主なカード

### 完全/実装寄せ
- うごくせきぞう: 正面に敵ユニットが1体もいない場合、ユニット/リーダー攻撃とも不可。
- デボラ: スキルリンク時、手札をレアリティが1つ上の別カードへ変換。
- デザートゴースト: 前列時、自分がデッキからカードを手札に加える度 +1/+1。
- トロデ: 自分がトロデにプラス系の単体特技/道具系を使った時、他の全ての味方ユニットにも同効果をコピー。
- エビルドライブ: 占い 1ドロー / 自身攻撃力+3。
- おばけトマト: 占い 敵ユニット1体の攻撃力を1 / HPを1。
- メタルドラゴン: 絶好調、占い デッキからコスト2以下絶好調ユニット2体を場に出す / 絶好調を持つ味方ユニット+1/+1。
- リゼロッタ&ルコリア: 占い 死亡した味方ユニット2枚を手札へ / 手札とデッキの攻撃力2以下ユニットカード+1/+1。
- セニカ: れんけい 敵1体に3ダメージ、全ての味方と味方リーダーを3回復。
- まおうのつかい: 自分ターン中、味方ユニットがダメージを受けたらそのユニット攻撃力+2。
- じごくのざりがに: 味方ピサロナイトが場に出る度、味方リーダーHP2回復。
- 地獄の帝王エスターク: HP満タン中は攻撃力-5、攻撃時に他の全ての敵へ同時ダメージ。
- エッグラ&チキーラ: 召喚時にタマゴ/ニワトリを選択し、相手予想が外れた場合の2効果を実装。現状はローカルテスト用モーダルで相手予想を代替。

### 既存の部分実装を補強
- マリンフェアリー: ランダムにコインを捨てた後、死亡した4コスト以下味方ユニット3種類から選択して復活。候補選択→マス選択に修正。
- フォレスドン: 死亡した4コスト以上味方ユニット3種類から選択して復活し、ターン終了時死亡。候補選択→マス選択に修正。
- ゲマ: 相手がデッキからカードを手札に加えた時、そのカードのコスト+1、敵リーダーに2ダメージ。
- 追撃のキラーマシン: 自分がさくせんを出した後、1ターン2回までランダムな敵ユニットに2ダメージ。

## まだ実戦で見たいところ
- エッグラ&チキーラ: マルチプレイ時に相手へ予想UIを出す同期処理。現状はローカルテスト代替。
- トロデ: マジカルハット同様、コピー対象はプラス系単体特技/道具系に限定。敵対象・変身・封印・全体効果は除外。
- ゲマ: 敵側ドロー経路が全て `drawForSideV114` を通っているかは継続監査対象。
- 地獄の帝王エスターク: 「他の全ての敵」処理は、攻撃対象以外の敵ユニットと敵リーダーへ同時ダメージで実装。
