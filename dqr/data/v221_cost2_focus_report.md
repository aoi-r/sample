# v221 コスト2重点チェック・batch4

## 反映した裁定

### オリハルゴン / リーダー攻撃
- 原則として、リーダーが「攻撃」として動けるのは1ターン1回まで。
- オリハルゴンがターンを跨いで場に残っている場合、次の自分ターンに再度1回攻撃可能。
- v220時点の `leaderAttackedThisTurn` ガードにより、常在再計算で攻撃権が復活しないことを確認。

### ホミロン軍曹
- 「敵マス」へ1ダメージずつランダム割り振りに修正。
- 敵ユニットがいないマスに当たったダメージは効果を発揮しない。
- 有効ヒット数をログに出す。

### ファーリス王子
- 公式テキストは「自分のターン終了時このユニットがブロックされているなら味方リーダーのテンション+1、カードを1枚引く」。
- 現在の実装は「自陣後列にいて、同じ段の自陣前列に味方ユニットがいる」場合をブロックとして判定。
- この解釈であれば特殊処理は問題なし。敵ユニットによるブロック等の別裁定なら要修正。

## 重点チェックからの補強

- グリーンシザー
  - 正面にいる敵ユニットとの戦闘時、このターン攻撃力+3。
  - 味方冒険者が場に出た後、そのユニットの前後の空きマスへ移動。
- ジャイアントバット
  - 召喚時、自身にさくせんを出す。
  - 戦闘ダメージを与えた敵ユニットを次の相手ターン終了時まで攻撃不能にする。
- コープスフライ
  - 前列にいる間、両プレイヤーのユニットカードの使用コスト+1。
- メーダ
  - 前列にいる間、両プレイヤーの特技カードの使用コスト+1。
- スカルガルー
  - 前列にいる間、デッキからカードを手札に加えるたび攻撃力+1。
- フロッガー
  - スライム系味方ユニットが場に出る度、ランダムな敵1体に1ダメージ。
