# v223 召喚/場に出す精密化・コスト2完了寄せ

## 少年テリー確認

少年テリー自身は `召喚時：味方リーダーのテンションスキルをモンスターマスターに変える` のため、手札から召喚した場合のみ `applySummonKeywords -> applySummonTextEffect -> applyCost2UnitSummonEffectsV218` 経由で処理されます。

一方、モンスターマスターや英雄竜の祝福などの「場に出す」経路は `putUnitIntoPlayFromCard` を使い、`unitPutIntoPlay` イベントを出すだけで `unitSummoned` は出しません。したがって、少年テリーが何らかの効果で直接場に出た場合、召喚時のテンションスキル変更は発動しません。

## v223で直した重要点

### 1. 場に出すユニットの基本キーワード保持

v222までは `putUnitIntoPlayFromCard` が召喚時効果を発動しないのは正しい一方、速攻・におうだち・絶好調・ステルスなどの印刷済み基本キーワードも落ちる可能性がありました。

v223では「場に出す」は召喚ではないが、基本キーワードだけは持った状態で出るように修正しました。

- 発動する: 速攻、におうだち、貫通、ねらい撃ち、ステルス、絶好調などの基本能力
- 発動しない: 召喚時、おうえん、召喚時扱いの対象選択、召喚時ダメージなど

### 2. モンスターマスター実装

少年テリーで変更されるテンションスキル「モンスターマスター」を実装しました。

発動時、以下からランダムに1体を味方優先空きマスへ「場に出す」。

- 青い闘魂スラぼう
- 豪腕王アントン
- 韋駄天のドラまさ

この処理は召喚ではないため、召喚時効果は発動しません。ただし、絶好調・速攻・におうだち・貫通・ねらい撃ちなど、カード本体に印刷された基本能力は保持します。

### 3. エビルスピリッツ

`このユニットの攻撃は味方リーダーの攻撃としても扱う` を追加しました。

エビルスピリッツが攻撃した後、味方リーダー攻撃扱いのフックを発火します。

- leaderAttackCount +1
- leaderAttacksThisMatch +1
- ヒーロー自動効果の leaderAttack フック
- ダンジョン/関連進行の leaderAttack フック

### 4. マリンスライム

`スキルブースト：攻撃力+1` を明示実装しました。

場にいるマリンスライムはテンションスキル使用時に既存のスキルブースト処理でも攻撃力が上がります。召喚時点でも既にテンションスキル使用回数がある場合、現在値を反映します。

## 要注意メモ

`putUnitIntoPlayFromCard` を強化したため、今後「場に出す」系で召喚時が勝手に発動する事故は避けつつ、カード本体の基本キーワードは落ちにくくなりました。

ただし、既存の個別処理で `game.player.board[pos] = makeUnitFromCard(card)` のように直接盤面へ置いている古い処理が残っている場合、その経路では基本キーワードが落ちます。次の段階で、直接代入している古い「場に出す」処理を `putUnitIntoPlayFromCard` へ寄せる監査をするのが安全です。
