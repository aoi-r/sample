# v219 ドラゴン重点チェック + コスト2ユニット batch2

## 反映した裁定・修正

- ドラゴンロードの「自分の手札のドラゴン系ユニットカードの使用コスト-1」は、召喚者側だけの手札コスト補正として維持・明記。
- v218ではドラゴンロードの盤面+1/+1が汎用常在オーラと専用処理で二重に入る可能性があったため、専用加算を停止し、汎用常在オーラに一本化。
- ドラゴンガイアの「相手の特技ダメージを受けない」は、ステータス付与だけでなく damageUnit / damageLeader 側で特技由来ダメージを0にする判定を追加。

## まだ怪しい/次に見たいもの

- ドラゴンガイアの「特技ダメージ」判定は、source名がカード名で入っている通常特技は通る想定。独自ログ名だけで発生する特技ダメージがあれば、そのsource名を追加する必要あり。
- コスト2では、位置移動系（キメラ、ナスビナーラ）、攻撃制限系（とつげきこぞう）、戦闘時誘発系（ピンクモーモン、グリーンシザー等）は次バッチで重点確認。
- 手札選択破棄は共通モーダル化したが、だんごスライム/立ち塞がるドラゴンで実機操作確認推奨。
