# v222 cost2 precision / Lamia orb / hero skill limit report

## 反映裁定

### ラーミア
- 召喚時、`シルバーオーブ / レッドオーブ / イエローオーブ / パープルオーブ / ブルーオーブ / グリーンオーブ` を召喚者の山札へランダム混入。
- オーブカードは既存DBカードを利用。
- オーブカード使用時は地形 `オーブ` として味方マスへ配置。
- 味方側の地形6マスがすべて `オーブ` になったら強制勝利。

### ヒポせんし
- 召喚者から見て敵リーダーのテンションが上がった実増加量ぶん、ヒポせんしの攻撃力を+1ずつ上げる処理を追加。
- 既存の `はえおとこ` など、敵テンションを直接上げる処理は `gainEnemyTensionV222` 経由に変更。

### ルイーダ
- 自分のターン終了時、公式DB分類ベースの `冒険者` 属性を持つ全ユニットからランダムに1枚を手札へ追加。
- 職業制限なし。

### ヒーロースキル2回上限系
- `ホワイトビート`：場にいる間、味方ヒーロースキルを1ターンに2回まで使用可能。
- `白煙のホワイトビート`：召喚時、次の相手ターン終了時までステルス。場にいる間、味方ヒーロースキルを1ターンに2回まで使用可能。
- `ヘンリー`：シンクロLv2でヒーロースキルコスト-1、Lv3で1ターン2回まで使用可能。
- 既存の boolean `heroSkillUsedThisTurn` に加えて、`heroSkillUseCountThisTurn` を導入。

### メドーサボール
- 味方ヒーロースキル発動後、自分の山札からシンクロを持つカードを1枚引く。
- 手動ヒーロースキル、自動ヒーロースキル双方でフック。

### キーファ
- 対象選択モーダル経由で、味方キーファに自分の特技カードを使った場合、その特技カードを記録。
- 死亡時、記録していた特技カードを自分の手札にコピーで戻す。
- 全体特技や対象を取らない特技の履歴は未対応。カード文面上「このユニットに使った特技」なので、対象選択経由を正として実装。
