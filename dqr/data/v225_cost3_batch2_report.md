# v225 コスト3ユニット batch2 実装・検証レポート

## 方針

- 「召喚」と「場に出す」は別物として維持。
- 手札から通常召喚したカードだけ `unitSummoned` / 召喚時効果を通す。
- 効果で出るトークン、死亡時復活、ランダム生成は `putUnitIntoPlayFromCard` 系を使い、召喚時効果を発動しない。
- 対象選択が必要なものは、可能な限り既存の共通モーダル `openChoiceModal` / `openUnitChoiceV224` に寄せた。
